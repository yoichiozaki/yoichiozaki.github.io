## Introduction

Welcome to my blog! It's built with Next.js (App Router) + MDX + Tailwind CSS and hosted on GitHub Pages.

## Tech Stack

This blog is built with the following technologies (versions reflect the current setup):

- **Next.js 16** — Static site generation with App Router (`output: "export"`)
- **React 19** — UI library, leaning on React Server Components
- **MDX** — Write blog posts with Markdown + JSX
- **Tailwind CSS v4** — Utility-first CSS framework
- **TypeScript** — Type-safe development
- **next-intl** — i18n for the bilingual Japanese/English content
- **Shiki** — Build-time syntax highlighting with light and dark themes
- **Mermaid** — Diagrams rendered to SVG on the client
- **GitHub Pages** — Free static site hosting

## Key Features

### Bilingual Support (Japanese / English)

Posts are published in both Japanese and English. You can switch languages with the toggle in the header.

### Dark Mode

You can switch between light mode and dark mode.

### Minimal Design

I kept the design plain, with readability as the priority.
