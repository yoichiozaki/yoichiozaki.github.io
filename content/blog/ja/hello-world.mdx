## はじめに

このブログを開設しました！Next.js (App Router) + MDX + Tailwind CSS で構築し、GitHub Pages でホスティングしています。

## 技術スタック

このブログは以下の技術で構築されています（バージョンは現行のもの）：

- **Next.js 16** — App Router を使用した静的サイト生成（`output: "export"`）
- **React 19** — UI ライブラリ。React Server Components を活用
- **MDX** — Markdown + JSX でブログ記事を記述
- **Tailwind CSS v4** — ユーティリティファーストの CSS フレームワーク
- **TypeScript** — 型安全な開発
- **next-intl** — 日英バイリンガル対応の i18n
- **Shiki** — ビルド時のシンタックスハイライト（ライト/ダーク両対応）
- **Mermaid** — 図表をクライアントサイドで SVG レンダリング
- **GitHub Pages** — 無料の静的サイトホスティング

## こだわりポイント

### 日英バイリンガル対応

日本語と英語の両方でコンテンツを提供しています。ヘッダーの言語切替ボタンから簡単に切り替えられます。

### ダークモード

ライトモードとダークモードを切り替えられます。

### シンプルなデザイン

読みやすさを重視したミニマルなデザインにしました。
